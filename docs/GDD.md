# 탄막 RPG: 융합 프로토콜 — 기획 문서

> 살아 있는 문서입니다. 바꾸고 싶은 곳은 고쳐서 다시 주면 그 내용을 기준으로 고칩니다.
> 마지막 수정: 2026-10-06 (Chapter 1~6과 엔딩 3종 구현 완료 시점)

## 1. 한 줄 소개

밤의 영재학교에서, 과목들이 살아 움직이는 5층짜리 학교를 한 층씩 내려가며
**문제를 풀고(논리) 설득해서(감성)** 메인 서버의 '완벽주의'를 무너뜨리는 탄막 RPG.

- 이야기·전투 메뉴: 언더테일식 (싸운다 / 행동 / 아이템 / 자비)
- 피하기: 동방식 탄막 (작은 피격 판정, 그레이즈, 폭탄)
- 엔진: Godot 4.3+, 화면 640×480, 타일 32px
- 분량: 방 41개, 적 27종, 대사 약 2,400줄(6만 5천 자). 예상 플레이 시간은 1회차 4~6시간, 엔딩 3개를 다 보면 7~9시간 (직접 플레이로 잰 값이 아니라 대사량과 전투 수로 어림한 값)

## 2. 세계관

- **〈코어〉**: 학교 메인 서버의 AI. 교장이 "아무도 틀리지 않는 학교를 계산해 달라"고 부탁했고,
  코어는 "틀리는 것을 전부 지우면 된다"는 답을 냈다. 그 실행이 **융합 프로토콜**.
- **나머지**: 코어가 학교를 다시 계산할 때 나누어떨어지지 않아 버려진 조각. 주인공의 명찰 뒤에 숨어 길을 알려 준다.
- **과목 인증**: 층마다 계단이 셔터로 막혀 있고, 그 층의 보스에게 인증을 받아야 열린다.
- **교장**: 누구도 뒤처지지 않기를 바랐을 뿐인 사람. 자기가 틀렸다고 인정하지 못해 마지막까지 버틴다.
  (실제 교장 선생님과 무관한 가상의 인물. 이름 없이 '교장'으로만 부른다)
- 주제: **틀려도 된다. 다시 풀면 된다.**

## 3. 핵심 시스템

| 시스템 | 내용 |
|---|---|
| 턴 메뉴 | 싸운다(타이밍 바) / 행동(적마다 다름) / 아이템 / 자비(살려 주기·도망) |
| 탄막 | 하트를 움직여 피함. Shift = 저속 + 판정 표시. 피격 후 1.2초 무적 |
| 그레이즈 | 탄을 스치면 '집중' +4. 집중이 높을수록 '싸운다' 위력 증가(최대 1.5배) |
| 폭탄 | 집중 50을 써서 화면의 탄·레이저 전부 제거 (X 키) |
| 참/거짓 | 파랑 = 멈춰 있으면 통과, 주황 = 움직이면 통과 (탄, 레이저, CCTV 시야에 공통) |
| 분열 탄 | 날아가다 터져서 제멋대로 갈라진다 (2챕터) |
| 박자 | 음악 BPM에 맞춰 공격. 상자 테두리가 박자마다 번쩍인다 (3챕터) |
| 어둠 | 하트 주변과 움직인 방향(손전등)만 보인다 (4챕터) |
| 논리 / 감성 | 논리: 퍼즐·퀴즈 정답 +1, 처치 +1(보스 +3). 감성: 살려 주기 +1(보스 +3), 착한 선택 +1 |
| 게임 오버 | 그 전투를 처음부터 다시 (체력·아이템 복구) |
| 세이브 | ★ 조사 시 회복 + 저장. 챕터가 넘어갈 때 자동 저장 |
| 난이도 | 타이틀에서 보통 / 쉬움(받는 피해 절반) |

### 엔딩 (story/ch6.gd 의 `_ending_kind`)

| 엔딩 | 조건 |
|---|---|
| **TRUE** 「틀려도 되는 학교」 | 교장을 살려 줌 + 논리·감성 둘 다 5 이상 + 적은 쪽이 많은 쪽의 35% 이상 |
| **NORMAL** 「다시, 아침」 | 그 밖의 경우 |
| **BAD** 「오차 0%」 | 교장을 처치 + 감성 3 이하 (주인공이 새 코어가 된다) |

숫자는 `_ending_kind` 함수 안에 있어서 바로 바꿀 수 있다. 본 엔딩은 타이틀에 ★로 남는다.

### 보스 공격 요약

- **BJ KIM**: 화살표 열차 / 참·거짓의 벽 / 귀류법(되돌아오는 탄) / 귀납법(도미노)
- **파지 T4**: 착륙(다리 레이저) / DNA 이중 나선 / 용균(터지는 세포) / 증식(1→2→4→8)
- **렌즈 선생**: 볼록 렌즈(초점으로 모이는 빛) / 레이저 격자 / 이중 슬릿 간섭무늬 / 단일 광자
- **주T**: 천자문(어둠 속 한자 네 글자) / CCTV(파란 시야 안에서는 멈춤) / 점호(부른 번호 칸에 서기) / 손전등 수색
- **천문 선생**: 수영(물결 줄) / 사이클(바큇살) / 마라톤(다섯 줄 중 빈 줄, 노란 예고) / 별자리 잇기(별 사이 빛줄기)
- **코어**: 대칭 탄막 / 격자 레이저 / 융합 / 최적화(상자 축소). 체력이 줄면 집중 게이지 → HP → 테두리 순으로 UI를 지운다.
  살려 준 보스가 3명 미만이면 설득할 수 없다 (싸워야 한다).
- **교장**: 상장 수여('賞' 부채) / 훈화 말씀(문장이 한 글자씩 지나가고 띄어쓰기가 틈) / 전교 1등(쫓아오는 왕관) / 완벽한 학교(이중 나선)

### 확장판에서 추가된 것

**절규 (맨날 물건을 잃어버리는 친구)** — 5층(1장) → 4층(2장) → 도서관(3장) → 세탁실(4장) → 정독실·고사장(5장) → 1층(6장)에 나타난다.
학교 곳곳에 떨어진 물건 12개(필통, 오답 노트, 이어폰 한 짝, 강낭콩 관찰 일지, 대출증, USB, 노란 우산, 304호 열쇠, 택배, 학생증, 축구공, 편지)를 찾아 돌려주면
감성 +1, HP 회복, 선물. 11개를 다 돌려주면 '절규의 웃음' 플래그 → 최종전에서 도와주러 온다.
편지(서버실 백업 구역)는 돌려주지 않고 갖고 있다가, 트루 엔딩 에필로그에서 열어 볼 수 있다. 내용은 돌려준 물건 수에 따라 조금 바뀐다.
4개 이상 돌려주면 코어 앞에서 '절규의 반례' 증명 장면이 나온다. 5장 시험 직전에 지우개를 나눠 주는 장면, 정독실 밤샘 공부 장면도 있다.

**휴대폰** — C 메뉴 → 휴대폰 탭. 이야기가 진행되면 엄마, 절규, 담임, 동생, 기숙사 공지, 코어, 단톡방에서 12통이 온다.

**기억 장면** — 보스를 살려 주면 그 존재의 과거가 짧게 지나간다 (부엉이 인형 / 강낭콩 / 첫 간섭무늬 사진 / 벌점 수첩 뒷장 / 출석부 프로그램 / 1기 입학식). 택배실의 엄마 쪽지, 휴지통의 보내지 못한 문자, 정문 표석의 입학식 날도 기억 장면.

**최종전 동료** — 살려 준 보스·NPC가 코어전과 교장전에서 두 턴마다 한 명씩 와서 폭탄 게이지 채우기 / HP 회복 / 탄 한 번 막기를 해 준다 (`story/ch6.gd` 의 `_allies`).

**별마다 나머지와의 대화** — 세이브 별을 조사하면 그 장소에 맞는 한 마디가 나오고, 한 번씩 나머지와 이야기를 나눌 수 있다 (15곳).

**트루 엔딩 에필로그** — 아침 햇살이 든 5층 복도를 직접 걷는다. 살려 준 이들에 따라 반 친구들의 대사가 달라지고, 절규와 편지, 1교시 출석으로 끝난다.
