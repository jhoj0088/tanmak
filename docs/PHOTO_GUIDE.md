# 학교 사진 촬영 가이드

사진은 두 군데에 쓴다.

1. **맵 배치**: 문이 몇 개인지, 어떤 순서인지, 방 안에 뭐가 있는지를 보고 맵을 실제 학교처럼 고친다.
2. **배경 그림**: 사진의 색 수를 줄이고 픽셀로 만들어서 전투 배경, 챕터 카드, 타이틀에 쓴다.

## 지금까지 받은 자료로 바꾼 것

**5층 시설 안내도** (저장소 `docs/reference/school-5f.png`, 2026-11-03 반영): 1~5층 복도 모양 전체를 이 평면에 맞췄다.
아래쪽 S동 가로 복도, 서쪽 끝 수학 구역(S512~S517), 동쪽 세모난 중앙 홀, 왼쪽 위로 뻗는 A동 사선 복도(A501~A509).
5층 문 명패는 안내도의 번호·이름 그대로다. D동은 넣지 않았다.

**1층·2층 사진** (2026-10-27):

| 사진에서 본 것 | 게임에 넣은 것 |
|---|---|
| 1층 가운데의 3층 높이 중앙 홀, 노란 둥근 기둥, 바닥의 마름모 무늬, 그랜드 피아노 | 안내도의 세모난 중앙 홀을 1층에서는 바닥으로 (기둥, 마름모, 피아노) |
| 'HALL OF FAME' 현판과 SASA 로고, "드높은 이상, 드넓은 창발" | 중앙 홀 위쪽 벽에 상장 진열장과 현판 (조사하면 문구가 나옴) |
| S110 앞 라운지: 검은 소파, 낮은 탁자, 분홍 스웨터 곰 인형, 빨간 우체통, 당구대(ATOZ) | 1층 S동 복도에 라운지 가구와 곰 인형, 당구대 |
| 2·3층 복도가 중앙 홀을 유리 난간으로 둘러쌈 | 2~5층 중앙 홀이 아래로 뚫린 세모 + 유리 난간 |
| 계단 표지 "3 도서관 / 2 대강당·방송실" | 3층 도서관, 2층 대강당(체육관)·**방송실** 배치, 2층에 같은 표지판 |
| 나무 창틀의 교실 벽, 노랑·보라·연두 칠한 벽 | 복도 벽의 창문·게시판 배치 |

**확인이 필요한 것**: 중앙 홀이 몇 층까지 뚫려 있는지(사진상 3층까지로 보임), 1~4층의 실 번호와 이름, 주 계단 위치.

## 찍는 법 (공통)

- **가로**로, **눈높이**에서, 수평을 맞춰서. 복도는 바닥 가운데 줄 위에 서서 소실점이 화면 가운데 오게.
- 광각(0.5배)을 써도 좋다. 단, 한 장소를 찍는 동안은 배율을 바꾸지 않는다.
- **사람 얼굴, 이름표, 개인 물건이 나오지 않게** 찍는다. 받은 2층 사진 중 두 장에는 사람이 찍혀 있어서 그림으로만 참고했다.
- 밝을 때 찍어도 된다. 밤 장면은 게임에서 어둡게 만든다.
- 올리는 곳: 드라이브 `양호연팀 정과프 → 배경 → 3층 / 4층 / 5층 / 옥상 / 야외` 폴더 (이미 만들어져 있고 비어 있음).
  파일 이름을 바꿀 필요는 없지만, 같은 장소는 **이어서** 찍어 주면 순서로 위치를 알 수 있다.

## 1순위: 1~4층 시설 안내도 (4장)

5층 것과 같은 **시설 안내도**(또는 계단 옆 피난 안내도)를 1~4층에서 한 장씩, 정면에서 글자가 읽히게 찍는다.
반사가 생기면 비스듬히 한 걸음 옆에서. **이 네 장이면 1~4층 문 번호와 이름을 5층처럼 정확히 맞출 수 있다.**

## 2순위: 건물 바깥 (옥상과 천문대 위치)

- **건물 옆면 전체**가 한 장에 들어오게, 운동장 쪽이나 기숙사 쪽에서 충분히 멀리 떨어져서.
  옥상 천문대 돔이 어느 동 위에 있는지 보이게. → 옥상 계단 위치를 맞춘다.
- 가능하면 정면 1장, 반대편 옆면 1장도.

## 3순위: 3층·4층·5층 복도와 방 (꾸밈용)

층마다 이 순서로 찍는다. (한 층에 약 10~15장)

| 컷 | 어디서 어디를 | 쓰임 |
|---|---|---|
| 복도 S | 중앙 홀(계단 앞)에 서서 S동 복도 끝까지 | 복도 길이, 문 수 |
| 복도 A | 같은 자리에서 반대로, A동 복도 끝까지 | 같음 |
| 명패 | 복도를 걸으며 **문 명패마다 한 장** (호실 번호와 이름이 읽히게. 예: S301 ○○실) | 문 순서, 방 이름 |
| 맞은편 | 복도 아래쪽 벽(화장실, 준비실 쪽) 문들 | 아래쪽 문 |
| 계단 | 계단 입구와 층 표지 | 계단 위치 |
| 중앙 홀 | 난간에서 내려다본 중앙 홀 (3층) | 발코니 모양 |

층마다 꼭 들어가 있는 방 (방 안을 문 앞에서 1장, 칠판 쪽 정면 1장):

- **5층**: A507 멀티디자인실(시작 장소), S512 강의실(수학), S516 교원연구실(수학, GIL 자리), S503 지구과학실험실1, A502 미술실1, A508 융합창작실1, 옥상 계단 입구
- **4층**: 생명과학 실험실(2장), 맥(Mac)실, 음악실
- **3층**: 도서관(입구, 서가, 열람석), 로봇실(창의설계실)
- **2층**(추가로 있으면): 단일광자 실험실(3장), 물리과 강의실, 서버실 문, 대강의실, 기숙사 연결 데크

## 4순위: 옥상 천문대 (5장 무대)

선생님 허락을 받고 찍는다.

1. 옥상으로 나가는 철문 (안쪽에서)
2. 문을 열고 나와서 옥상 전체 (난간이 보이게)
3. 천문대 돔 바깥 (돔 문이 보이게)
4. 돔 안: 망원경 전체, 돔이 열리는 틈, 벽에 붙은 성도나 관측 기록표
5. (선택) 맑은 밤의 옥상 하늘 1장: 타이틀 배경으로 쓴다

## 5순위: 기숙사·야외

- 기숙사: 연결 데크, 기숙사 복도, 세탁실, 정독실 (각 1~2장)
- 야외: 정문과 표지석, 운동장(본관을 바라보고), 정원·연못

## 배경 그림용 (있으면 좋은 것)

보스 방마다 **보스가 서 있을 자리를 정면으로** 1장: 수학과 교실 칠판(BJ KIM), 생명과학실 실험대, 단일광자 실험실 광학 테이블, 천문대 망원경(천문 선생), 서버실.
